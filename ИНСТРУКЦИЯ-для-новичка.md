# Как запустить Wool & Hornet Planning — пошагово для новичка

Эта инструкция проведёт вас от «у меня есть папка с файлами» до «инструмент открывается по ссылке у всей команды». Никакого опыта не требуется. Делайте по порядку.

Всего два больших этапа:
- **Этап A** — запустить у себя на компьютере и проверить, что всё работает.
- **Этап B** — опубликовать в интернете, чтобы открывалось у коллег.

---

## Этап A. Запуск на своём компьютере

### Шаг 1. Установить Node.js

Node.js — это программа, которая умеет запускать наш сервер.

1. Откройте сайт https://nodejs.org
2. Скачайте версию с пометкой **LTS** (это стабильная версия).
3. Запустите скачанный файл и установите, нажимая «Далее» / «Next» до конца (настройки по умолчанию менять не нужно).

Проверка, что установилось:
- **Windows:** нажмите `Win`, наберите `cmd`, откройте «Командную строку».
- **macOS:** откройте программу «Терминал» (Spotlight → наберите `Terminal`).

В открывшемся окне введите команду и нажмите Enter:

```
node -v
```

Если увидите что-то вроде `v20.11.0` — всё хорошо, Node установлен. Если пишет «command not found» / «не является внутренней командой» — перезагрузите компьютер и проверьте снова.

### Шаг 2. Положить папку проекта в удобное место

Возьмите папку `wool-planning-server` (со всеми файлами: `server.js`, `package.json`, папкой `public` и т. д.) и положите, например, на Рабочий стол.

### Шаг 3. Открыть терминал внутри этой папки

Нужно, чтобы терминал «смотрел» именно в папку проекта.

**Способ, который работает везде** — команда `cd` (перейти в папку). В терминале введите `cd `, поставьте пробел, затем перетащите папку `wool-planning-server` прямо в окно терминала мышкой (путь подставится сам) и нажмите Enter. Пример того, что получится:

```
cd /Users/ivan/Desktop/wool-planning-server
```

Подсказки для конкретных систем:
- **Windows:** можно открыть папку в Проводнике, в адресной строке набрать `cmd` и нажать Enter — откроется терминал уже в этой папке.
- **macOS:** правый клик по папке → «Новый терминал в папке» (если включено в настройках), либо способ с `cd` выше.

Чтобы убедиться, что вы в нужной папке, введите:
- Windows: `dir`
- macOS: `ls`

Вы должны увидеть в списке `server.js` и `package.json`. Если их нет — вы не в той папке, повторите `cd`.

### Шаг 4. Установить «детали» проекта

Введите одну команду и нажмите Enter:

```
npm install
```

Пойдёт скачивание (нужен интернет). Это займёт от 10 секунд до пары минут. Появится новая папка `node_modules` — так и должно быть, трогать её не нужно. Предупреждения (`warn`) можно игнорировать; важно, чтобы не было красных `error`.

Эту команду достаточно выполнить **один раз**.

### Шаг 5. Запустить сервер

```
npm start
```

Если всё хорошо, появится строка:

```
Wool & Hornet Planning слушает http://localhost:3001
```

Готово — сервер работает. **Это окно терминала теперь нельзя закрывать**, пока пользуетесь инструментом: оно и есть работающий сервер.

### Шаг 6. Открыть и проверить

1. Откройте браузер, введите в адресную строку: `http://localhost:3001`
2. Создайте комнату (название фичи, ваше имя, команда) → «Создать комнату».
3. Нажмите «Копировать ссылку».
4. Откройте эту ссылку во **втором окне браузера** (или в режиме инкогнито) — войдите под другим именем. Это имитация второго участника.
5. Проголосуйте в обоих окнах — увидите, как всё синхронизируется вживую.

Чтобы **остановить** сервер — вернитесь в окно терминала и нажмите `Ctrl + C`.

Чтобы запустить снова в следующий раз — повторите Шаг 3 (зайти в папку) и Шаг 5 (`npm start`). `npm install` больше не нужен.

> На этом этапе ссылка работает только на **вашем** компьютере. Чтобы её открывали коллеги — переходите к Этапу B.

## Этап B. Публикация в интернете (чтобы работало у команды)

Самый простой для новичка путь — платформа **Railway**: она сама возьмёт ваш код, установит всё и выдаст рабочую ссылку. Отдельный сервер и настройка Nginx не нужны.

### Шаг 1. Завести код на GitHub

Railway берёт код из GitHub, поэтому сначала загрузим папку туда.

1. Зарегистрируйтесь на https://github.com (бесплатно).
2. Установите **GitHub Desktop**: https://desktop.github.com — это программа с кнопками, без командной строки.
3. В GitHub Desktop: `File → Add local repository` → укажите папку `wool-planning-server`. Если предложит «create a repository» — согласитесь.
4. Внизу слева напишите любое описание в поле Summary и нажмите **Commit**.
5. Нажмите **Publish repository** (можно оставить галочку «Keep this code private» — репозиторий будет закрытым).

Готово: код на GitHub.

### Шаг 2. Развернуть на Railway

1. Зайдите на https://railway.app и войдите через GitHub («Login with GitHub»).
2. Нажмите **New Project** → **Deploy from GitHub repo**.
3. Выберите репозиторий `wool-planning-server`. Дайте доступ, если Railway попросит.
4. Railway сам поймёт, что это Node-проект, установит зависимости и запустит `npm start`. Подождите, пока сборка завершится (несколько минут).

### Шаг 3. Получить публичную ссылку

1. Откройте ваш проект в Railway → вкладка **Settings** сервиса.
2. В разделе **Networking** нажмите **Generate Domain**.
3. Появится адрес вида `https://wool-planning-production.up.railway.app` — это и есть ваша ссылка. Она уже с HTTPS (это важно: без него не работают «Копировать ссылку» и стабильное соединение).

Отправьте этот адрес команде — инструмент открывается у всех.

### Шаг 4 (важно). Сохранять эталон между обновлениями

По умолчанию накопленный эталон (файл `data.json`) может теряться при каждом передеплое. Чтобы этого не было, подключите постоянный диск:

1. В Railway откройте сервис → **Settings** → раздел **Volumes** → **Add Volume**.
2. Укажите путь монтирования, например: `/data`
3. Откройте вкладку **Variables** и добавьте переменную:
   - имя: `DATA_FILE`
   - значение: `/data/data.json`
4. Сохраните — Railway перезапустит сервис. Теперь эталон хранится на постоянном диске и переживает обновления.

### Шаг 5. Как обновлять инструмент в будущем

Когда захотите что-то поменять:
1. Внесите правки в файлы в папке.
2. В GitHub Desktop нажмите **Commit**, затем **Push origin**.
3. Railway сам увидит изменения и передеплоит новую версию за пару минут.

## Если что-то пошло не так

- **`node` / `npm` не распознаётся как команда** — Node.js не установлен или нужно перезагрузить компьютер после установки (Шаг 1 этапа A).
- **`npm install` падает с ошибкой сети** — проверьте интернет; если вы за корпоративным прокси/VPN, попробуйте из другой сети.
- **Страница `http://localhost:3001` не открывается** — убедитесь, что окно терминала с `npm start` ещё открыто и в нём есть строка «слушает…». Если закрыли — запустите `npm start` снова.
- **Порт занят (`EADDRINUSE`)** — сервер уже запущен в другом окне, либо порт занят. Закройте лишние окна терминала или запустите на другом порту: `PORT=4000 npm start` (macOS) / в Windows: сначала `set PORT=4000`, затем `npm start`.
- **Кнопка «Копировать ссылку» не срабатывает** — это нормально на `http://localhost` в некоторых браузерах; в интернете (Этап B, там HTTPS) всё работает. Ссылку всегда можно скопировать из адресной строки браузера.

## Короткая шпаргалка команд

```
node -v            # проверить, что Node установлен
cd путь/к/папке     # зайти в папку проекта
npm install        # установить зависимости (один раз)
npm start          # запустить сервер
Ctrl + C           # остановить сервер
```
